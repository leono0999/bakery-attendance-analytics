## 📖 Overview

The **Bakery Attendance Analytics Dashboard** is an end-to-end Business Intelligence solution developed to automate employee attendance processing for a local bakery.

The project transforms raw attendance records exported from a biometric time clock into reliable business information through an automated Python ETL pipeline, PostgreSQL analytical views and interactive Power BI dashboards.

In addition to business analytics, the solution automatically generates personalized employee attendance reports by updating protected Excel templates while preserving their existing formulas and formatting.

# 🎯 Business Problem

The bakery managed employee attendance using Excel files exported from a biometric time clock.

This process involved:

* Duplicate punches
* Missing check-outs
* Repeated records
* Manual calculations
* Monthly Excel reporting
* Time-consuming attendance verification

Managers needed an automated solution capable of cleaning attendance data, generating reliable employee reports and providing interactive business insights.

# 🏗 Solution Architecture

![alt text](bakery_attendance_pipeline_2.png)

### Pipeline Workflow

The solution follows this process:

1. Raw attendance files are placed inside the **data/raw** folder.
2. A single orchestration script (`run_pipeline.py`) executes the complete pipeline.
3. Python cleans and validates attendance records.
4. Three processed datasets are generated:

   * attendance_report
   * employee_summary
   * odd_punches
5. Clean information is loaded into PostgreSQL.
6. SQL analytical views provide the reporting layer.
7. Employee Excel templates are automatically updated while preserving formulas.
8. Individual attendance reports are generated.
9. Power BI consumes the SQL views to build interactive dashboards.

# ⚙ Automated Attendance Processing Pipeline

## Project Folder Structure

```text
data/

├── raw/
│     Raw attendance files exported from the biometric system.
│
├── processed/
│     attendance_report.xlsx
│     employee_summary.xlsx
│     odd_punches.xlsx
│
├── templates/
│     Employee attendance templates containing protected formulas.
│
└── reports/
      Automatically generated employee attendance reports.
```

## Extract

Attendance records are imported from Excel files generated by the biometric attendance system.

## Transform

The ETL performs:

* Duplicate removal
* Timestamp conversion
* Punch validation
* Entrance calculation
* Exit calculation
* Total worked hours calculation
* Attendance anomaly detection
* Employee attendance summarization

## Load

The pipeline produces multiple outputs.

### Processed Data

* attendance_report.xlsx
* employee_summary.xlsx
* odd_punches.xlsx

### PostgreSQL

Clean attendance information is loaded into PostgreSQL.

### Excel Automation

Employee attendance templates are automatically updated while preserving existing formulas and formatting.

### Reports

Final employee attendance reports are generated automatically.

# 🚀 How to Run

1. Clone the repository.
2. Install dependencies.

```bash
pip install -r requirements.txt
```

3. Place the attendance Excel file inside:

```text
data/raw/
```

4. Execute:

```bash
python run_pipeline.py
```

5. Refresh the Power BI dashboard.
